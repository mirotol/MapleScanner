About MapleScanner

Free Market prices for MapleStory Classic, read from your game window and shared between players.

It only reads the screen

Everything comes from the picture of the game window, the same as a screenshot. MapleScanner never touches the game's memory, files, network traffic or ports.

What it sends

Prices need internet. MapleScanner sends the shop listings it read off your screen (item, seller, amount, price, channel, room and shop title) with an anonymous key made when it was installed. The key identifies the install, not you, and the price server keeps only a scrambled copy of it. Your IP address isn't stored.

Seller names are public, as they are in the game. It never sends pictures of your screen, and nothing about your account.

Open source

MapleScanner is free software under the GNU GPL, version 3 or later. The source code is on GitHub, so anyone can check what it does, and so are the release notes.
