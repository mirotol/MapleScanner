Code signing policy

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

What is signed

The Windows app (MapleScanner.exe) and its installer (MapleScanner-Setup-<version>.exe). Both are built by GitHub Actions from the public source code, on GitHub's own machines, and signed only after a person on the team approves that release. Nothing built on a personal computer is signed.

The libraries the app is built on, such as Electron, are other projects' work and are included as they come.

Team roles

  • Committers and reviewers: mirotol
  • Approvers: mirotol

Changes from anyone else, such as pull requests, are reviewed by a committer before they're merged.

Privacy

MapleScanner goes online for three things:

  • Prices. It downloads the shared price list from MapleScanner's own server, api.maplescanner.app, which runs on Cloudflare.
  • Sharing scans. With Share my scans on, it sends the shop listings it read off your screen to the same server, with an anonymous key for the install. The installer asks before anything is sent, and Settings turns it off at any time. What it sends lists exactly what goes out.
  • Updates and item icons. It checks GitHub Releases for a new version, and downloads each item's icon once from OSMS Data Explorer.

It never sends pictures of your screen or anything about your account, and never reads the game's memory, files or network traffic. The price server doesn't store IP addresses.
