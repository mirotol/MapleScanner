## MapleScanner has its own icon

The app now has an icon of its own: a scan frame around a maple leaf. You'll see it on the taskbar, on the desktop and Start menu shortcuts, and on the installer, in place of the plain default one.

If a shortcut still shows the old icon after updating, Windows is showing a saved copy. It catches up by itself, usually after a restart.

## Small fixes on the Prices tab

Opening an item no longer draws an outline around its close button, which made it look selected.

In a narrow window, each item's price confidence is now worded the same way as in the wide list, like `●○○ 3 sellers`, with the cheapest ask on a line of its own. An open item keeps only its name and the close button at the top while you scroll.

Nothing to do: everything applies as soon as you update.
