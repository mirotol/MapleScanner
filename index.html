MapleScanner

Ready when the game is

Start the game in a window at the default UI size, then start scanning. The picture stays on this PC. Only the listings read from it are shared, with every MapleScanner player.

  1. Place the stall card next to the game. It stays on top.
  2. Walk into a shop and scroll its list.
  3. Hover an item to see what it's worth.

Settings

Show or hide the stall card Press this key while playing to hide the card or bring it back. The game doesn't get this key while MapleScanner is open, so pick one your own MapleStory key setup doesn't use. A key on its own is safest, because holding Ctrl, Alt or Shift also does something in the game.

About MapleScanner

Version

Free Market prices for MapleStory Classic, read from your game window and shared between players.

Updates

What it sends

Prices need internet. MapleScanner sends the shop listings it read off your screen (item, seller, amount, price, channel, room and shop title) with an anonymous key made when it was installed. The key identifies this install, not you, and the price server keeps only a scrambled copy of it. Your IP address isn't stored. Seller names are public, as they are in the game. It never sends pictures of your screen, and never touches the game's memory, files or network traffic.
