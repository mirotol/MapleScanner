Ready when the game is

Start the game in a window at the default UI size, then start scanning. The picture stays on this PC: nothing is uploaded.

  1. Place the stall card next to the game. It stays on top.
  2. Walk into a shop and scroll its list.
  3. Hover an item to see what it's worth.
Or paste a screenshot with Ctrl+V, or drop one here. Screenshots of the same shop add up.
How prices work

Every shop you scan is shared with every MapleScanner player, and their scans give you prices. Only what is on screen is sent: the listings read and an anonymous install key, nothing else. Each seller gets one vote, so nobody can move a price by listing more. The usual price is what items sold for, once 3 sellers have sold one over at least 2 days. Until then it's the low end of what sellers ask. It uses the last 3 days when 3 sellers are known, otherwise 7 or 14, and shows a price range until 3 sellers have listed an item. Gear is only compared with the same stats, so hover it first. NPC prices come from OSMS Data Explorer.

On each row the white tick is what the item sold for and the dot is this listing. A dotted line means few sellers, and no line means it can't be compared yet.

Something not working?

If no shop is ever found, turn off HDR in Windows display settings.

Saving a test frame stores what the scanner sees, so a problem can be looked at.

Recording saves every frame for 30 seconds, with what was read from each, so a problem that comes and goes can be looked at.

Settings

Show or hide the stall card Press this key while playing to hide the card or bring it back. The game doesn't get this key while MapleScanner is open, so pick one your own MapleStory key setup doesn't use. A key on its own is safest, because holding Ctrl, Alt or Shift also does something in the game.
